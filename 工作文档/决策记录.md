# 画台 · 决策记录

> 用途：**防新对话重开已决事项**（照《对话交接规范》§5：每条写清"当时为什么这么定"）。
> 规矩：**只追加**。要改结论就追加一条新的并注明推翻哪条，**不许抹掉旧的**。
> 记录时间：2026-10-12（画台从零到闭环那一天）

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
| 1 | **活代码放哪** | 整套（代码+数据+exe）放**工作区外**的 `D:\画台\` | 实测：工作区里的 exe 是 **Low 完整性** ⇒ WebView2 崩 `8000ffff`；工作区外是 High。**只有 exe 位置是变量，cwd 无关**。代价：会话需要 full-access |
| 2 | **界面形态** | Wails 壳（Go + 手写前端）替换 streamlit | 用户："streamlit 约束多"；且新需求（画布/多版对比/大图预览）streamlit 撑不住 |
| 3 | **前端要不要 npm** | **不要**：`frontend/dist` 直接 `go:embed`（`wails.json` 的 build 命令留空） | 少一个 JS 工具链、少一处网络风险；代价是"改前端要重编 exe"。照参考项目那份配置抄的形状 |
| 4 | **壳和服务怎么说话** | **一条业务两条通道**：**stdio 默认**（不占端口）+ **HTTP 保留**（调试 / 将来 JS 3D 展示） | stdio 子进程随壳生死 ⇒"服务没起/端口被占/僵尸服务"整类消失；HTTP 是用户点名保留的 |
| 5 | **内核：搬还是重写** | **搬**（`kernel\` = 从 bestpic 拷），`bestpic\` 从此**冻结为参考代码** | 那是唯一**验证过**的资产（回归 9/9、orders 18/18、UI 冒烟 34/34）；重写等于把验证过的地基拆了 |
| 6 | **账的形状** | 一单一个目录；**`src_*` 只进不改**；**`transcript.jsonl` 只追加**；流水必须**三分**（material/user/assistant/action/system） | 图和话都不可逆；"人说的话"与"机器给的结论"混在一行 ⇒ 聊天区会掺满内部日志 |
| 7 | **单 = 什么** | **单 = 一张图 + 一段对话**（一个工程可以有很多单） | 与内核一致（bestpic 决策 #7「每张图/每单活 = 一个 session_id」） |
| 8 | **第一版吃什么料** | **只吃图片**；其他料一律**明说读不了** | 用户 2026-10-12："其他资料以后再说"。而且"读不了"本身就是"不许假成功"的真实用例 |
| 9 | **小助手怎么说话** | 用**甲**：运行态 agent **只出 JSON**（`action`/`question`/`knobs`/`local`），**界面转述它的话** | 不放松"只出 JSON"这条铁律 ⇒ 可控、可复现、成本可预测（放松后最贵那次实测 30k token 会变常态） |
| 10 | **能力清单从哪来** | **从同一份代码渲染**（`capabilities.py`），**绝不在提示词里手写第二份** | 手写必漂，漂了就是"假装生效"。判据：改一处清单 ⇒ 小助手的回答跟着变（已用钩子验过） |
| 11 | **上下文** | **每轮现拼要点卡 + 只带最近 6 轮、每轮截 200 字** | 参考包判据 8：会话无限堆积 ⇒ 输入量随对话变长没有上限 |
| 12 | **旋钮语义** | **累积状态**，不是"某次回复的残影"（只覆盖明确写出的那几个） | 老项目欠的 `FIX-2`/`FIX-1`：说一句"背景白一点"只写一个旋钮，按默认值重建会**静默归零**之前调好的 |
| 13 | **判据怎么算** | **独立回读**：管线自报的墨点占比，再从 **BMP 反算**一遍 | 同一个函数既改图又算分叫"同源自证"；从产物反算才是证据 |
| 14 | **缺口旋钮** | 允许写（名字合法），但**必须三处显式上报**"写了不生效" | 静默忽略就是"假装生效"；用户要那个效果时助手必须说清楚 |
| 15 | **自检分两层** | `--selfcheck` **免费**（42 项）；真机调用必须显式加 `--with-brain` | **自检不许偷偷花钱**——否则顺手一跑，账就悄悄涨 |
| 16 | **空的"默认工程"** | 界面里**隐藏**（内核照旧自动建它，删了还会建） | 用户 2026-10-12：它只是噪音。**但它一旦有单就必须显示**——只藏空的，绝不藏数据 |
| 17 | **"回到上次"** | 下沉为后端动作 `session.latest`（跨工程取**最近更新**那一单） | 写在前端就是一段没人验得着的猜测；**内核的工程列表恒把「默认工程」排第一**，前端"取第一个"必错（用户踩过） |
| 18 | **界面布局** | **一页到底**；输入框**常驻底部**（多行，可拖大）；选工程**自动打开最近一单** | 用户反馈："切工程不显示对话、也没输入框，还要先点物料，太复杂了" |
| 19 | **界面源码进版本库** | `shell\.gitignore` 里**去掉** `frontend/dist`（保留 `build/bin`、`*.syso`） | wails 模板把它当 Vite 构建产物忽略；**本方案不用 npm，那就是手写源码** ⇒ 照模板配会让界面永远不在版本库里 |
| 20 | **运行时会话不进版本库** | `.gitignore` 必须含 `.dsh_home/` 与 `.agent-cwd/` | 参考包口径：**运行时会话是缓存，产品对话流水才是账**；而且它 zstd 压缩、格式随版本变、会无限增长 |
| 21 | **判据钩子** | `HUATAI_CAP_SWAP=glass:0` 这类环境变量，**只在验证时用** | 它存在的唯一理由：让"改一处清单 ⇒ 回答跟着变"这条判据**真的能验**，否则只能靠嘴说 |
| 22 | **测旋钮要用什么图** | 必须用**有高频细节**的图 | 平滑渐变上 USM（细节保留度）本来就不起作用，拿它测会得出"旋钮坏了"的**假结论**（踩过） |
