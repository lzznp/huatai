## 1 ★★ 本场最重要的一条认识（也是我自己上一场的方案被推翻）
上一场（#36）定的取向 B 是："**灰度层减淡 → 只对选区重仿色**"。
本场先按这个做，结果在判据⑤上反复失败，最后查明**它不是"余量不够"，是原理上做不到**：

> **Floyd–Steinberg 的误差 = 灰度 − 决策。**
> 一个像素要延续的误差，**同时**取决于框外像素的**灰度**与它们的**决策**；
> 而框外的决策又取决于更早的像素……⇒ 想只重算一个小框、又要求它与全图重仿一致，
> 等于要求"裁掉输入的前半段、输出却必须与完整输入相同"。

**实测五种引子的差距**（`tests\probe_brush2_why_global.py`，可重跑；已写区 **2617** 点）：

| 引子做法 | 已写区与"全图重仿"不一致 |
|---|---|
| 只留 2px 余量 | **1598** 点 |
| 留 4 行 / 20px 带 + 框外喂当前点阵 | **1598** 点（一样） |
| 只把上带的**决策**喂进去 | **1598** 点 |
| **整块都喂当前点阵**（最省事） | 1145 点，**而且框内被全钉死 ⇒ 一根点都没改**（等于没刷） |

⇒ **选定口径（决策 #46）**：拖动中**只动灰度**（快、保手感）；**松手时对当前灰度做一次全图重仿**，
成品在"已写区"取 `基线点阵 ∧ ¬重仿结果`（只删不补）。这样**"已写区 = 全图重仿"是按定义成立**的。

### 2.4 ★ 本场后半段的四处修正（都是"看图才发现"的，别只看数字）

写完第一版自检全绿之后，我把默认参数的一笔导出成对比图**自己看**，发现画面被"挖了个硬边的洞"。四处连锁修正：

| # | 问题（看图发现的） | 根因 | 改法 |
|---|---|---|---|
| 1 | 改后是**硬边白洞** | "只删不补"取 `基线 ∧ 重仿`，而 FS 对 1 级灰度变化就整体挪位 ⇒ 交集 ≈ 密度平方（20.0% 与 18.9% 交集 **4.2%**） | 护栏1 **重定义**为"净墨点只减不增、圈外永不新增"（#50）；成品 = 重仿结果 |
| 2 | 一笔就把强度用满 | 覆盖累加 0.18，一笔横扫被 8~9 个印子叠满（1.4） | `COVER_STEP` 0.18 → **0.06**（一笔只到 ~0.5） |
| 3 | 边界像"贴出来的" | 羽化只有 0.3×半径 ≈ 8px | `FEATHER` 0.3 → **0.5**（≈13px） |
| 4 | 强度数字没有意义 | 单位是"灰度级"，35 级 ≈ 14 个墨点百分点 | 改成**墨点百分点**（默认 2.0）（#51） |

## 3 ★ 顺手抓到的"判据骗人"（v1 自检的假失败）
`python tests\exp_smart_brush.py --selftest` 现在有 **1 项 FAIL**，但**导出没坏**：

- 失败项：`★★导出：1bit 成品与内部点阵逐像素一致`；
- 根因：**判据取错了文件**。导出文件名只有 `HHMMSS`（无日期），跨天后 `sorted()` 是字符串序，
  把**昨天的** `brush171619-...` 当成了最新的；
- 反证：单独验导出往返（两种口径、两种尺寸、含非 8 倍数宽度）**全部逐像素一致**；
- 处置：**v1 不修**（它是历史物证）；**v2 的导出一开始就改成** `%Y%m%d-%H%M%S`，
  且 `export()` **返回本次真正写出的文件清单**，判据不再靠排序猜。

> 教训（值得记住的通用形态）：**判据的"取材方式"本身也要被验**。取错一个文件，就会得出"东西坏了"的假结论。

## 4 用户点名要查的 artcraft：**没有减淡工具**（实锤，带出处）

用户问："`参考代码\artcraft-main` 是 PS 平替开源，里面应该有减淡工具的相关实现吧，我们是否可以参考？"

**结论：它没有减淡/加深工具，这条线没有现成件可抄。** 证据：

| 查什么 | 结果 |
|---|---|
| 工具表 `frontend\libs\components\pagedraw\src\lib\components\ui\SideToolbar.tsx`（L270–313） | 只有 **Brush（纯色+opacity+size）/ Mask / Eraser / 形状 / Canvas Background** |
| 画笔实现 `...\pagedraw\src\lib\PaintSurface.tsx`（L359–394） | 只有 `source-over`（画）与 `destination-out`（擦），**没有减淡/加深的混合或像素算子** |
| Rust 侧像素算子 `crates\lib\files\images\` | 只有**缩放与编码**（resize / PNG / WebP / mask 归一化），**没有曝光/曲线/色阶** |
| 全仓 `dodge|burn` 命中（17 处） | **全在视频合成层的混合模式**（`color-dodge` / `color-burn` 枚举与下拉项），与"灰度减淡工具"不是一回事 |

**但有一条结构可借鉴（只学结构，不搬代码；#31）**：它的每一笔落在**独立数据节点**上、
**可累积、可整笔撤销**；橡皮走 `globalCompositeOperation="destination-out"`。
⇒ 与我们"笔笔有账、护栏在代码里"同向，本场实现也是"每笔一个快照、精确撤销"。
